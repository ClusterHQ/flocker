==================
Flocker with Swarm
==================

To use Flocker in Docker Swarm, you must use our experimental Powerstrip_ project.

For more details, please refer to our blog post: `Moving a database container with Docker Swarm and Flocker`_.

.. _Powerstrip: https://github.com/ClusterHQ/powerstrip

.. _Moving a database container with Docker Swarm and Flocker: https://clusterhq.com/2015/03/25/migration-database-container-docker-swarm/
